# Form AutoFill Studio

1. `pip install -r requirements.txt`
2. `playwright install chromium`
3. `python app.py`
4. Open http://127.0.0.1:5000

Upload CSV/XLSX (columns: Name, Email, Phone Number, Message), tick the permission box, press Start.
The browser window opens visibly so you can watch each row and handle any CAPTCHA by hand.
